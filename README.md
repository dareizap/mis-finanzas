# Mis finanzas

App web de finanzas personales: resumen mensual, movimientos, presupuesto por categoría y metas de ahorro.

- Funciona 100 % en el navegador (un solo archivo `index.html`, sin dependencias).
- Los datos se guardan en el navegador del dispositivo (localStorage).
- Moneda: pesos colombianos (COP). Para cambiarla, edita la función `cop` en `index.html`.

## Cómo usarla en local

Abre `index.html` con doble clic en tu navegador.

## Cómo publicarla con GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `mis-finanzas`).
2. Sube `index.html` y `README.md` a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y pulsa **Save**.
5. Espera 1 o 2 minutos. Tu página quedará en `https://TU-USUARIO.github.io/mis-finanzas/`.
